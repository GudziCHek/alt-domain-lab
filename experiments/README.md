# Эксперименты

Здесь хранятся протоколы опытов: вопрос, исходные условия, метод, ожидаемый и фактический результат, вывод и границы проверки. Исходные скриншоты и выводы команд находятся в `evidence/<дата>/`; общий прогресс — в [исследовании](../docs/research.md) и [журнале](../docs/journal.md).

E09 оформлен отдельным протоколом: опыт включает исходный доменный вход, создание локального тёзки, воспроизведение сбоя после перезагрузки, изменение настройки и повторные входы. Такая структура позволяет повторить проверку и отдельно оценить доказательства.

Результаты E01 и E02 пока сохраняются в существующих разделах исследования. Для следующих опытов можно использовать структуру протокола E09; незаполненные протоколы не считаются выполненными проверками.
