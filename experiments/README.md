# Эксперименты

Здесь хранятся протоколы опытов: вопрос, исходные условия, метод, ожидаемый и фактический результат, вывод и границы проверки. Исходные скриншоты и выводы команд находятся в `evidence/<дата>/`; общий прогресс — в [исследовании](../docs/research.md) и [журнале](../docs/journal.md).

Отдельными протоколами оформлены E03, E04, E09 и обе части E05: обои и доступ к съёмному носителю. Каждый протокол связывает исходное состояние, изменение и проверку результата. Восстановление DNS, времени и рабочего входа записано как [обслуживание стенда](../docs/time-synchronization.md), без нового номера эксперимента.
