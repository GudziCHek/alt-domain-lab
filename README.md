# Управление доменом в ALT Linux

Учебный проект по дисциплине «Операционные системы».

## Цель

Развернуть домен на ALT Linux с помощью Samba AD, подключить две рабочие станции и проверить управление пользователями и политиками через ADMC.

## Вопрос исследования

Как проверить, что доменные учётные записи и политики работают на двух клиентах, и как отличить ошибку настройки от ограничения или дефекта ADMC?

## Планируемая работа

* Настроить стенд из контроллера домена и двух клиентов.
* Проверить вход одной доменной учётной записью на обоих клиентах.
* Настроить и проверить парольную политику и одну групповую политику для клиентов.
* Сравнить результаты операций в ADMC с данными командных инструментов.
* Проверить поведение системы при ошибочных действиях и описать результаты.

## Текущее состояние

Контроллер домена dc1 настроен и проверен. Следующий этап — установка и подключение двух клиентов.
