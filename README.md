# Управление доменом в ALT Linux

Учебный проект по дисциплине «Операционные системы».

## Цель

Развернуть домен на ALT Linux с помощью Samba AD, подключить две рабочие станции и проверить управление пользователями и политиками через ADMC.

## Вопрос исследования

Как проверить, что доменные учётные записи и политики работают на двух клиентах, и как отличить ошибку настройки от ограничения или дефекта ADMC?

## Текущее состояние

Результаты на **1 октября 2026 года**; документация дополнена 3 октября.

Узел         | ОС                                     | Адрес      | Подтверждённый результат
-------------|----------------------------------------|------------|-----------------------------------------------------------
dc1.lab.test | ALT Server 11.1, редакция «Альт Домен» | 10.77.0.10 | Контроллер lab.test работает; зарегистрированы оба клиента
pc1.lab.test | ALT Workstation 11.2                   | 10.77.0.21 | Вход student1, идентификация пользователя и билет Kerberos
pc2.lab.test | ALT Workstation 11.2                   | 10.77.0.22 | Вход того же student1, совпадение UID/GID и билет Kerberos

Оба клиента подключены через SSSD. Положительная проверка E01 — вход одной доменной учётной записью на двух компьютерах — выполнена.

Применение конкретных политик и операции через ADMC ещё предстоит проверить. На dc1 зафиксировано предупреждение ядра soft lockup; после него Samba была активна, причина задержки пока не установлена.

## Следующие проверки

* Подключиться к домену через ADMC и сравнить объекты с данными командных инструментов.
* Проверить создание пользователя и изменение членства в группе.
* Настроить и проверить парольные требования и одну поддерживаемую групповую политику.
* Провести отрицательные проверки и описать фактическое поведение системы.
