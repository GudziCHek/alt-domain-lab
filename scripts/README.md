# Скрипты

Каталог для будущих вспомогательных скриптов проверки и сбора данных стенда. Готовых скриптов здесь пока нет.

Выполненные вручную команды описаны в [инструкции](../docs/setup.md) и [протоколах экспериментов](../experiments/README.md), а их результаты — в `evidence/`. История команд эксперимента не считается скриптом для безусловного повторного запуска.
