## Как открыть

1. Распаковать архив. Для добавления к проекту скопировать содержимое каталога alt-domain-lab в C:\alt-domain-lab, сохранив структуру папок.
2. Открыть нужный .dia через «Файл → Открыть» в Dia. Прямоугольники, подписи и соединения являются отдельными редактируемыми объектами. Узлы с подписями сгруппированы; для правки отдельной подписи можно разгруппировать узел.
3. Для печати задан A3 с альбомной ориентацией и размещением схемы на одном листе. Масштаб можно изменить в настройках страницы.

Схема входа показывает обязанности компонентов. Она не утверждает, что каждый NSS-запрос обращается к серверу или что все этапы выполняются ровно по одному разу. Офлайн-вход по паролю на стенде ещё не проверялся. Главный источник доменных учёток — Samba AD на dc1; клиентский кеш не превращает пользователя в локальную запись /etc/passwd.

Оба файла .dia проверены чтением и экспортом в Dia 0.97.3. PNG и SVG получены из этих схем; подписи и внутренние ссылки проверены.

Диаграммы находятся в presentation/diagrams, потому что используются для объяснения и демонстрации архитектуры. docs содержит техническое пояснение; evidence остаётся местом для фактических выводов и скриншотов проверок.
