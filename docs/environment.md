# Окружение проекта

## Основной компьютер

* **Операционная система:** Windows 11 Home x64
* **Процессор:** AMD Ryzen 7 250 с Radeon 780M
* **Оперативная память:** 16 ГБ, из которых ОС доступно 15,3 ГБ
* **Накопитель:** SSD объёмом в 1000 ГБ, свободно 767 ГБ

## Программное окружение

* **Среда виртуализации:** VirtualBox 7.2.16 r174877.
* **Терминал для работы с Git:** Git Bash.
* **Каталог проекта в Windows:** `C:\alt-domain-lab`.

## Планируемый стенд

Один контроллер домена на ALT Linux и две клиентские виртуальные машины. Фактические версии гостевых ОС, параметры ВМ и настройки сети будут добавлены после их установки и проверки.
