# Окружение проекта

## Основной компьютер

* **Операционная система:** Windows 11 Home x64
* **Процессор:** AMD Ryzen 7 250 с Radeon 780M
* **Оперативная память:** 16 ГБ, из которых ОС доступно 15,3 ГБ
* **Накопитель:** SSD объёмом 1000 ГБ; на начало работы было свободно 767 ГБ (текущий остаток: 672 ГБ).

## Программное окружение

* **Среда виртуализации:** VirtualBox 7.2.16 r174877.
* **Терминал для работы с Git:** Git Bash.
* **Каталог проекта в Windows:** `C:\alt-domain-lab`.

Состояние на 9 октября 2026 года. Контроллер и оба клиента установлены; E01/E02 выполнены на двух клиентах, E09 — на pc2.

## Домен, сеть и версии

* Домен: `lab.test`; realm Kerberos: `LAB.TEST`; NetBIOS: `LAB`.
* Сеть VirtualBox: NAT Network `ad-lab`, `10.77.0.0/24`; шлюз `10.77.0.1`.
* DNS dc1: `127.0.0.1`, бэкенд `SAMBA_INTERNAL`; клиентский DNS: `10.77.0.10`, поиск `lab.test`.
* Последний проверенный внешний forwarder dc1: `172.17.2.11` (3 октября, после смены внешней сети). Его доступность зависит от окружения.
* Samba на dc1: `4.21.9-alt4.p11.1`; ADMC на pc1: `0.24.0-alt1`; SSSD на pc2: `2.9.8-alt3.x86_64` (проверен 9 октября).
* На клиентах используется подключение через ЦУС: «SSSD в единственном домене». Флажок поддержки групповых политик включён; применение конкретной GPO ещё не проверено.
* После обновления 1 октября проверено ядро `6.12.110-6.12-alt1` на всех трёх узлах. Тогда же подтверждены синхронизация времени и активность NTP; точный источник синхронизации отдельно не установлен.

Доменные UID/GID относятся к текущему домену. Одинаковые пути на разных ВМ не означают общее хранение файлов. `student2` также входит в `lab-students`, GID `1164001107`.

На pc2 в `[domain/LAB.TEST]` задано `use_fully_qualified_names = true`, добавлена связь роли `domain users@LAB.TEST:users`. Для доменного входа используется полное имя; локальный e09same остаётся коротким. На pc1 это изменение SSSD не выполнялось. Итоговые графические входы E09 проверены на pc2; графический вход student2 после изменения имён там отдельно не повторялся.

## Сохранение состояния

Пользователь подтвердил создание снимков `after-e02-2026-10-09` и `after-e09-2026-10-09` для dc1, pc1 и pc2. Скриншоты менеджера новых снимков в подборку не входят; восстановление не проверялось. На pc2 также сохранены резервные копии SSSD и ролей. [Сведения о точках сохранения](../evidence/09-10-2026/vm-snapshots.txt).
